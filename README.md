**글빛(Geulbit)** 은 한글 음절을 초성, 중성, 종성으로 정교하게 분해하여 각각의 자소에 아름다운 색상을 입혀주는 웹 기반 시각화 도구입니다. 

한국어 교육을 위한 시각 자료, 디자인 프레젠테이션, 타이포그래피 실험 등 한글의 구조적인 아름다움을 직관적으로 보여주고 싶을 때 유용하게 활용할 수 있습니다. 🎨

---

## 🌟 주요 기능

* 🧩 **정교한 자소 분리**: 완성형 한글 음절을 초·중·종성 단위로 완벽하게 분해하여 렌더링합니다.
* 🎨 **테마 및 색상 커스터마이징**: 미리 준비된 아름다운 색상 템플릿을 사용하거나, 직접 원하는 색상을 헥스(Hex) 코드로 입력해 조합할 수 있습니다.
* 📏 **다양한 배치 모드**: 기본 모아쓰기뿐만 아니라, 자소의 구조를 펼쳐서 보여주는 **자모 그리드 모드**를 지원합니다.
* 📥 **고품질 내보내기**: 작업한 결과물을 배경이 투명한 **PNG** 또는 벡터 형식인 **SVG**로 즉시 다운로드할 수 있습니다.
* 📦 **일괄 ZIP 다운로드**: 여러 글자를 한 번에 입력하면, 압축 파일(ZIP) 하나로 묶어서 간편하게 저장해 줍니다. (중복 글자 필터링 지원)
* 🌍 **다국어 지원**: 한국어, 영어(English), 터키어(Türkçe) UI를 지원합니다.

## 💡 사용 가이드

누구나 쉽게 5단계만으로 멋진 한글 시각 자료를 만들 수 있습니다.

1. **글자 입력**: 왼쪽 화면의 텍스트 박스에 원하는 한글 문장을 입력하세요.
2. **색상 입히기**: `색상` 탭에서 초/중/종성의 색을 직접 고르거나, `템플릿` 탭에서 조화로운 팔레트를 클릭해 보세요.
3. **스타일 다듬기**: 글꼴 굵기(일반/굵게), 자소 겹침 순서, 미리보기 크기를 취향에 맞게 조절합니다.
4. **결과 미리보기**: 오른쪽 `미리보기` 창과 `음절 분석` 패널에서 자소별로 잘 분리되었는지 확인합니다.
5. **다운로드**: `내보내기` 탭에서 개별 파일이나 ZIP 형태로 결과물을 PC에 저장합니다!

## 🛠 기술적 특징 (Technical Details)

글빛은 단순히 이미지를 자르거나 겹쳐놓은 것이 아닙니다. 
**`opentype.js`** 엔진을 활용해 `UnDotum` 폰트 내부의 **Composite Glyph(복합 글리프)** 정보를 직접 파싱합니다. 이를 통해 각 자소가 화면에 그려지는 벡터 패스(Vector Path) 데이터를 실시간으로 추출하고 재조합하여, 웹상에서 왜곡 없는 완벽한 고해상도 SVG를 렌더링합니다.

## 🚀 로컬 개발 환경 구성

글빛 프로젝트를 직접 로컬에서 실행하고 수정해 보고 싶으신가요? 
[Node.js](https://nodejs.org/) (LTS 버전 권장)가 설치되어 있어야 합니다.

```bash
# 1. 의존성 패키지 설치
npm ci

# 2. 로컬 개발 서버 실행
npm run dev
```

서버가 실행되면 브라우저에서 `http://localhost:5173` 으로 접속해 주세요.
*(Windows 환경이라면 프로젝트 폴더 내의 `start.bat` 또는 `start.py`를 실행하셔도 됩니다.)*

### ✅ 검증 및 빌드

```bash
# 단위 테스트 실행 (음절 분해, 자모 분류, 레이어 순서 등 검증)
npm test

# 프로덕션 빌드 (dist/ 폴더에 정적 파일 생성)
npm run build

# 빌드된 결과물 로컬에서 미리보기
npm run preview
```

## 🌐 자동 배포 (GitHub Pages)

이 프로젝트는 `main` 브랜치에 코드가 푸시될 때마다 **GitHub Actions** 워크플로가 작동합니다.
자동으로 의존성을 설치하고, 테스트를 거쳐 안전하게 프로덕션 빌드를 수행한 뒤, 최종 결과물을 [GitHub Pages](https://baggychani.github.io/Geulbit/)에 배포합니다.

## 📁 프로젝트 구조

```text
📦 src/
 ┣ 📂 components/   # UI를 구성하는 React 컴포넌트들
 ┣ 📂 hooks/        # 폰트 로딩 및 전역 상태 관리 커스텀 훅
 ┣ 📂 utils/        # 폰트 파싱, SVG/PNG 내보내기, 다국어 처리 등 핵심 로직
 ┣ 📜 App.jsx       # 메인 애플리케이션 화면
 ┗ 📜 index.css     # 전역 및 유틸리티 스타일 (디자인 시스템)
📦 tests/           # Node.js 기반의 단위 테스트(Unit Tests)
📦 public/          # UnDotum 폰트 및 파비콘 등 정적 에셋
```
